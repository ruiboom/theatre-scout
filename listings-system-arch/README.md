# Anywhere But The West End — Project Files

A listings site for London's 70 non-West End theatres, with an AI-native discovery layer planned for v2.

> **Status:** name is a placeholder; soft launch targeted for 1 September 2026; MCP/AI launch ~Oct/Nov 2026.
